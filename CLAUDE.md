# Hollow Saint: notes for Claude

A top-down pixel auto-shooter for iPhone landscape, in one file with no build
step. Read `docs/HANDOFF.md` first: it holds the current state, the
owner's preferences and a prioritised list of ideas to tackle next.

## Where things are

| Path | What |
|---|---|
| `index.html` | The whole game (about 7,300 lines, Canvas 2D). The `T` table at the top holds tuning (`T.viewH` = 305, the view height; matches the Otherworld Legends phone camera); `WS = 1.3` is the world scale |
| `assets/sprites/*.png`, `sprites.json` | Generated sheets (committed). Never edit them by hand |
| `tools/sprites.mjs` | Builds every sheet. Older hand-drawn art lives here; sculpted models override it by anim name |
| `tools/sdf.mjs` | The sculpted pixel-art renderer (SDF shapes, smooth union, lighting, palette banding, outlines). `setRes(2)` renders on a 2x2 grid. `render(..., { rich: true })` (rounds 78-79, every monster and hero; `NORICH=1` previews without it) blends a figure: more melt, cast shadows between parts, seam creases, cloth folds and flesh lumps |
| `tools/chunky.mjs` | Snaps any frame to the 2x2 chunky grid (the Otherworld Legends blocky look); run on every sheet except `ui` |
| `tools/models/*.mjs` | Model sets: `base` (materials + Saint model, `HEROES` for the Mendicant), `saint`, `mendicant`, `common`, `rare`, `elite`, `townfolk`, `town`, `dungeon`, `floor` (flagstones, water), `vfx` (effects, icons, loot, HUD sound icon), `props` (3/4-view furniture, pilasters, floor bits, HUD buttons), `weapon` (the floating crossbow, 16 angles), `street` (town street props and ground decals), `pets` (the twenty pets from one builder, four frames each, and the Indulgence icon) |
| `assets/audio/*.mp3` | Sound effects, music and ambience (committed). Effects: `python3 tools/build-sfx.py <src> [names]` (layered CC0 takes, hall reverb, levelled); music loops: `tools/build-audio.sh <src>`. Packs in `docs/CREDITS.md` |
| `docs/CREDITS.md` | Every asset source and licence. Add to it when you add an asset |
| `docs/ART_COMPARISON.md` | Otherworld Legends vs our art: the gap list, map layout recipe, camera and pixel-size measurements |
| `tools/palette.mjs` | Master palette: 26 ramps × 9 steps (`sea` is the water ramp). Every pixel must be on it |
| `tools/preview.mjs` | Render one model set to a PNG for review |
| `tools/icon.mjs`, `assets/icons/` | The app icon (the Saint's bust in a violet-lit arch, 64x64 chunky art): apple-touch-icon 180, favicon 32, 192 and 512 for `manifest.webmanifest`. Rebuild with `node tools/icon.mjs`; `node tools/icon.mjs out.png 6` previews |
| `tools/tests/*.cjs` | Playwright checks (see below) |
| `docs/GDD.md` | Design bible (source of truth) + the v5 art spec |
| `docs/COMBAT.md` | Rooms, 30 monsters, affixes, loot, town layout |
| `docs/ROADMAP.md` | Vertical-slice checklist |
| `docs/SETS.md` | The five vestment sets: design and how they are built |

**Dev menu:** open with `?dev` (it stays on), the backquote key, or five quick taps in the bottom-left corner of the pause screen; then the DEV tile on the pause screen. Tabs (`DEV_TABS`, one help line each in `DEV_HELP`): HERO (god mode, levels, Wounds, Saint level, rite ranks, Testaments for the Calling), GEAR (items at any Station and rarity, whole sets with arms, the bag), FORGE (Emberstones, force the next reforge quality, enchants on worn gear, ingredients, the altar), WORLD (descend to any Station or stratum, summon any Warden or monster, the Vigil, the yard), TOWN (unlocks, currencies, looks, Censer, bounties, cells), PETS (Indulgences, own and equip pets, the follower, an Indulgence drop, the shop) and DEBUG (fps, profile, hitboxes, game speed, errors, the save). In `devRows()` each row is `R(label, ...cells)` with up to three cells; `< X >` buttons are pickers (grey), `on` makes a toggle (green when on), `danger` marks a destructive button; end a tab with `{ info }` for its status line. Keep a tab to seven rows. `tools/tests/dev.cjs` checks every label fits.

Add `?prof` to the URL to fill `HS.PROF` with per-system ms per frame. Each test writes screenshots to `<outDir>/shots/` and prints `errors 0 []` when clean. `?fps` shows frames per second and the ms our own code takes per frame. Look at the screenshots yourself; the user cares most about how it looks.

## Conventions

- **Art rules (from the owner):**
  - No visible separation of body parts: build forms with smooth union (`k` ≈ 1–2).
  - Lit from the top-left.
  - Hand-place eyes with `dot()`.
  - Use `folds()` on cloth and `bumpy()` on flesh and stone.
  - No dithering mush and nothing that looks AI-made.
  - Every pixel must be on the palette.
  - Chunky pixels: art ships on a 2x2 grid (each art pixel is 2 world pixels), so details under 2 px vanish. Keep thin parts (halos, strings, rims) at least 2 px thick and check with `CHUNKY=1` previews. The screen always uses a whole-number scale with nearest-neighbour pixels.
  - Characters face right; the engine flips them.
  - Every character frame sets `ax`/`ay` at the feet.
  - Furniture is drawn in 3/4 view: pass `tilt` (about 0.3 to 0.6), `tiltY` (the ground line) and `tiltLift` to `render()` so the top face shows (see `tools/models/props.mjs`).
- **Model sets:** a set exports `{ sheetName: { animName: () => frames } }`. `sprites.mjs` loads it automatically if its name is in the list near the top. Monster anims are `<id>_walk` (8 frames from half steps, `HALF` in `base.mjs`), `<id>_attack` (3 frames = windup, windup2, strike; `rear(make)` in `base.mjs` builds windup2 by tipping the wind-up pose back), and `<id>_hit` (2) and `<id>_die` (3) from `reactions(make)`. Use `stride()` for legs so feet stay planted. Bob bodies with `bobAt()` (whole 2 px steps); a 1 px bob makes the sprite shimmer.
- **World units:** distances in `index.html` are world pixels at the v5 scale. Any new size or range should already include the ×1.3 scale. MON stats are written at the old scale and multiplied by `WS` in a loop after the table.
- **Floor tiles:** stay 16 px (`TILE`). Back walls are 3 tiles tall plus a cap: `hall.wall` = [top, cap, upper, lower, mid].
- **Shipping:** raise `BUILD` near the top of `index.html` every round (it versions asset URLs and lets running games reload into the new build) and add the round's lines to `CHANGES[BUILD]` (shown once to returning players). Work on a branch, then push to `master`. The owner asked for every finished round to go to master; GitHub Pages deploys from it. End commits with the attribution lines the session asks for.
- **Names:** never borrow names or terms from other games (the owner removed all Blasphemous and Diablo terms for copyright). Our terms: Zeal (resource), Reckoning (ultimate), Rites (skills; 12 choosable in `RITES`: Holy Water, Baptism, Nail Storm, Ember Step, Chain of Penance, Shackle Circle, Censer Blaze, Martyr's Ward, Rain of Reckoning, Judgement, the Great Font, the Hundredfold), the Stations (difficulty, I–XXX, `MAX_STATION`, in bands Pilgrim/Zealot/Martyr/Saint/Ascetic/Anchorite/Apostle, `bandOf`), the Toll (progress bar), the Warden (the Station boss; five of them), Sanctity (gear power from item level), the Bleeding Vigil (timed endless trial, opened with Bloodrose Keys), knells (Toll orbs), omens (map curses), the Weeping Reliquary (an event), Hallowed (top rarity; 37 named pieces in `LEGENDS`, 7 of them the Mendicant's), the Ashen Altar (burn a Hallowed piece to learn its power, three sockets), Vigil Trials (endless mode), health orbs, Carnage bonus, the Saint level (1–100, account level) and its talents (three trees at the Canonry), reforge and temper (the Ember Forge; Emberstones, reforge qualities common to mythic), the Enchanter and its 16 enchants (ingredients from Wardens of Station X and deeper), Pell's curio stall, the vestment sets (the Hundred Nails, the Penitent's Stride, the Drowned Font, the Last Confessor, the Burning Choir, Odile's Habit, the Lesser Vow, Odile's Gift, Penitent Cells and absolution, the Anchoress (reliquary shards, the Shattered Reliquary, the Glass Martyr, the Mother's Psalter, the Veiled Lantern, the Thorned Crucible, the Anchorite's Shroud), the Mendicant's sets (the Beggar King's Iron, the Wanderer's Road, the Almsgiver's Bowl, the Gaoler's Keys, the Cracked Bell, the Mendicant's Rags; Momentum, Alms, Fetters, rings, crushes), Graven and Beatified lines, Reliquary Tears, the Arms of each set: the Nailwright's Arbalest, the Hundredfold Quiver, the Pilgrim's Ember-Bow, the Quiver of Coals, the Aspergill Arbalest, the Brimming Case, the Penance Engine, the Quiver of Links, the Canticle Bow, the Quiver of Candles), Stratum II the Drowned Nave (Silt Wretch, Nave Eel, Tide Cantor, the Tide-Bishop, the Drowned Organist), Stratum III the Ossuary Spire (Bone Gleaner, Cinder Moth, Marrow Abbot, the Ossuarch, the Ash Widow), the Training Yard, kill streaks, Rubrics (support skills for rites), the Calling and Testaments (class talent tree and its points), Indulgences (premium currency), pets (Nail Finch, Censer Mouse, Alms Hound, Bell Crow, Glass Moth, Votive Wisp, White Lamb, Stone Cherub, Ember Imp, Pilgrim Hare; - **Saint skins:** `SKINS` in `tools/models/base.mjs` (materials + one detail per set) build `saint_<set>` and `portrait_<set>`; `saintSheet()` in `index.html` picks one at 4 set pieces. Draw the Saint through `saintSheet()`, never `'saint'` directly. Skins also swap the crossbow (`xbow_<set>`) and bolt (`bolt_<set>`, `BOLT_FX`).
- **Hallowed and heroes:** a `LEGENDS` entry may carry `hero` ('saint' or 'mendicant'): it drops only for that hero.
- **Item icons:** draw any piece with `itemIcon(it, x, y)`; it uses the Hallowed piece's own icon (loot `legend`, LEGENDS order, `LEGEND_ICONS` in `vfx.mjs`), a set piece's (loot `setitem`, set * 10 + slot, `SET_LOOK` in `vfx.mjs`), or the slot icon. A new Hallowed piece or set needs new icons.
- **Sounds:** add a recipe to `SFX` in `tools/build-sfx.py`, its name to `SFX` and `VOL` in `index.html`'s `AUDIO`, and its pack to `docs/CREDITS.md` (CC0 preferred). Play with `sfx(name, { vol, rate, gap, bus })`, or `sfxAt(name, x, y, o)` for a monster's sound (fades with distance). Attack sounds (round 77): `swing`, `mace`, `mswing`, `mcast`, `mslam`, `cast`, `glass`; a new attack type needs a line in `performAttack`'s sound picker. (`bus: 'sfx'` keeps a voice sound off the voice bus). Music loops are `music()` recipes in the same script and `LOOPS` in `AUDIO`; loops that follow the Saint (`amb_choir`, `amb_fire`) are in `LEVELED` and set by `AUDIO.level`. A new monster needs a `VOICE` family; a new Warden needs `roar_<id>`, `fall_<id>`, an earned halo in `HALOS` (plus a `halostand` frame). Voices (`die_`, `roar`, `fall_`) play on their own bus (`AUDIO.isVoice`). Battle music while a Warden lives: `music_warden`, `music_warden_nave`.
- **Looks:** the Saint is always drawn through `saintSheet()`, which applies the Plush stall look (`lookSheet`). The pause panel's bust is `bustAnim()` (ui `portrait`, `portrait_m`, `portrait_a`; a new class needs one in `townfolk.mjs`).
